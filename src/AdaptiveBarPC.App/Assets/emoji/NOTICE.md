# Fluent Emoji 3D

These 32 unmodified PNGs are from Microsoft's Fluent Emoji repository:
https://github.com/microsoft/fluentui-emoji/tree/1ffb34c752ecf5d402f04cfb4b392c77f57c54bc/assets

Each file is named after its complete Unicode sequence in lowercase hexadecimal,
with hyphens between code points (including variation selectors). Hand gestures
use the upstream `Default/3D` assets; other emoji use `3D` assets.
The picker uses local images only and still inserts Unicode text, not images.
